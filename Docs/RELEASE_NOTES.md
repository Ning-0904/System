## 🎯 核心功能

### ✅ 已实现功能

**1. 双层工作流可视化（论文对齐）**
- 主层（M1~M6）：子问题迭代总览
- 子层（S1~S8）：每个子问题内部推理闭环
- 补检轮次可视化、延迟显示、状态追踪

**2. 20+法律案例数据集**
- 16个法律领域覆盖
- 每个案例包含：问题、子问题、推理指标、实体流行度
- 支持难度/领域筛选（数据结构预留）

**3. 动态工作流生成**
- S1~S8节点完全基于问题内容生成
- 不依赖硬编码，支持任意法律问题
- 检索决策、查询重写、充分性判断均为动态

**4. 浅色主题美化**
- 背景#f8fafc（清爽白）
- 文字#1e293b（高对比度深灰）
- 主色蓝紫系（#2563eb / #7c3aed）
- 专业感与可读性提升

**5. 数据管理页（P0完成）**
- 数据源管理：5个数据源，含检索策略
- 领域数据库：实体流行度（含阈值可视化）、术语映射、法律结构库
- 历史记录面板（占位完成）

**6. 首页多问题检测**
- 支持多个主问题输入识别
- 自动拆分为任务队列
- "每次输入一个主问题"提示

## 🚀 使用指南

### 启动开发服务器
```bash
cd e:/大论文/System/frontend
npm run dev
```

### 首页体验
1. 打开 http://localhost:5173/
2. 选择"法律适用推理"场景
3. 从右侧选择一个法律案例（支持10个）
4. 点击"开始推理演示"进入工作流展示

### 推理展示页体验
- **左侧面板**：任务概览、进度指标、子问题列表
- **中间上层**：主工作流（M1~M6子问题迭代）
- **中间下层**：子工作流（S1~S8推理闭环）
- **右侧面板**：选中节点的详细信息（字段按节点类型渲染）

### 数据管理页体验
- 5个数据模块导航
- P0模块完整可用（数据源、领域数据库）
- 实体流行度含阈值可视化
